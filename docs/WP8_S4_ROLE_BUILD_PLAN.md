# WP8 S4 — separate Core and Taster production build delivery plan

Proposed sequencing for owner review; documentation only. Baseline `017e948f6480169b60ceb77642f1ac4fdb38e58e` (PR #34 merged). Governing specification: [Core and optional wireless Taster](PP_DESIGN_SPEC.md#core-and-optional-wireless-taster). S3g2j has passed host regression, independent source review and the isolated actual ESP32-S3 object compile ([exact evidence](https://github.com/ConnalM/Plonk-and-Play/pull/34#issuecomment-7146886723)); no application link or runtime qualification is implied. Retain the integrated development/acceptance arrangement and accepted image/build tree.

## Role contract (already approved)

Core is required, screenless ESP32-S3 with all analogue detectors, timing, Race Control/Engine, microSD, records, shared preferences and SMUGLAND; works with no accessory. Optional 800x480 ESP32-8048S070 Taster is a presentation/control client only, exclusive STA with protected pair/locator storage, no Core sporting, Browser, SD/history/records authority or remote detectors. One source base, two distinct images, no third product. Browser takeover, unofficial standalone eligibility, fixed Taster behaviour, automatic connection/selection, no codes/extra hardware/router, first-use trust limitation and safe non-replay remain unchanged. No automatic displacement of a live peer. Frozen designs remain frozen.
